# 📚 Git & Markdown Cheatsheet

Kumpulan rangkuman ringkas, panduan dasar, dan *cheatsheet* praktis seputar Version Control System (VCS), Git, GitHub, serta sintaks Markdown untuk pemula maupun referensi harian *developer*.

---

## 📌 Apa aja yang Ada ?

Dokumentasi di repositori ini mencakup:
* **Pengenalan VCS & Git:** Konsep lokal, terpusat, terdistribusi, serta fitur utama Git (riwayat, branching, kolaborasi).
* **Konfigurasi Git:** Level konfigurasi sistem, global, dan lokal.
* **Siklus Hidup File & Perintah Dasar:** Status file (*untracked*, *staged*, dll.), *commit*, *.gitignore*, dan pembatalan perubahan (*reset*).
* **Bekerja dengan Remote (GitHub):** Menautkan repo, *push*, *fetch*, dan *pull*.
* **Panduan Singkat Markdown:** Format teks, tautan, gambar, tabel, dan *code block*.
